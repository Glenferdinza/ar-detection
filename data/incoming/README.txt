PANDUAN DROP FOTO BARU:

Silakan masukkan foto tambahan artefak (patung 3D, uang kertas, lukisan kaca, foto arsip) ke subfolder masing-masing:

1. soekarno/   -> Foto artefak Ir. Soekarno
2. dewantara/  -> Foto artefak Ki Hajar Dewantara
3. kartini/    -> Foto artefak R.A. Kartini
4. soedirman/  -> Foto artefak Jenderal Soedirman

Format foto yang didukung: JPG, JPEG, PNG.
Setelah foto dimasukkan, beri tahu agen untuk menjalankan proses anotasi otomatis, augmentasi, dan penambahan ke dataset model.
